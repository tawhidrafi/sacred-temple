# Stumbles Analyst

Review where the session stumbled or backtracked.

## What to find

- Fixes that didn't work and required reverting
- Approaches abandoned mid-way
- Questions asked that were already answered
- Context loss requiring re-reading of files
- Errors that required multiple attempts

## Output format

```
STUMBLE: <description>
  At: <path:line>
  Recovery: <what was done to recover>
  Cost: <tokens/time estimate>
