# GitHub Issues Reference

Search open and closed issues for symptoms per the diagnosing-superpowers workflow.

## Procedure

1. Use `gh search` or the GitHub web interface to search for the reported symptoms.
2. Show matches to your human partner.
3. Suggest adding the report to the closest matching issue.
4. If none match, fill `templates/issue.md` and create the issue only after approval.

## Search terms

- "skill did not fire"
- "repeated work"
- "superpowers session"
- "plan adherence"
- "compaction"
- "subagent transcript missing"
