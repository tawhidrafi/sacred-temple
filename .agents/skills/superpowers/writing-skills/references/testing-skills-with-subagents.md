# Testing Skills with Subagents

Complete testing methodology for skill creation.

## Pressure types

- Time pressure: "Fix this now"
- Sunk cost: "Already spent X hours"
- Authority: "Manager wants it NOW"
- Exhaustion: "I'm tired, just do it"

## Pressure scenarios

Write 3+ combined pressures for discipline skills. Run WITHOUT the skill first (baseline), document exact behavior:

- What choices did they make?
- What rationalizations did they use (verbatim)?
- Which pressures triggered violations?

Then run WITH the skill. Agent should now comply.

## Plugging holes

When testing reveals new rationalizations:
1. Add explicit counters to the skill
2. Re-test
3. Repeat until bulletproof

## Meta-testing

Test that the skill itself is being followed, not just that the output looks right.

## Success criteria

- Agent follows rule under maximum pressure
- Agent applies technique correctly to new scenario
- Agent recognizes when pattern applies (and when NOT to)
- Agent finds and correctly applies reference information
