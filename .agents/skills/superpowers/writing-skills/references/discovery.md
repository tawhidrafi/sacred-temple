# Discovery

How future agents find your skill:

1. Encounters problem ("tests are flaky")
2. Searches skills (greps descriptions, browses categories)
3. Finds SKILL (description matches)
4. Scans overview (is this relevant?)
5. Reads patterns (quick reference table)
6. Loads example (only when implementing)

Optimize for this flow — put searchable terms early and often.

## Naming

Use only letters, numbers, hyphens. No parentheses or special characters.

## Description

Starts with "Use when..." Includes specific triggers and symptoms. Written in third person. Max 1024 chars.

## Keywords

Include searchable terms: errors, symptoms, tools, conditions. These help agents find the skill when searching.

## Cross-referencing

Reference other skills by name: `superpowers:skill-name`. Use this to link related skills.
