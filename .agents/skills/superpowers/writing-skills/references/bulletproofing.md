# Bulletproofing

Close loopholes in discipline-enforcing skills.

## Closing loopholes

When a baseline failure is a discipline failure (agent knows the rule but violates it under pressure):

1. Add prohibition + rationalization table + red flags
2. Express exceptions as conditionals on observable predicates, not nuance clauses
3. No exemption clauses that suppress entire categories of output
4. Micro-test wording before full scenarios

## Spirit vs letter

Violating the letter of a rule is violating the spirit. Enforce both.

## Rationalization table

| Excuse | Reality |
|--------|---------|
| "Just this once" | No exceptions |
| "It's simple" | Simple cases have root causes too |
| "I'll do it later" | Later never comes |
| "Everyone else does it" | That's not a reason |

## Red flags list

List thoughts that mean STOP:
- "Quick fix for now"
- "Just try X and see"
- "Skip verification"
- "I'm confident without evidence"
