# Signs

Signs of slop to audit for in unslop.

## Visual signs

- Purple gradients, glows, gradient text
- Emoji used as icons or decoration
- "New ✨" or "Beta 🚀" badges
- Glossy blobs, orbs, nebulas
- Uppercase tracked labels
- Uneven spacing, one-off margin values
- Glowing bars, rainbow bars in charts
- animate-pulse, animate-ping on non-live elements
- transition-all
- Hover:scale on cards
- Gradient wordmarks, sparkle tiles

## Copy signs

- Exclamation marks in interface text
- Greeting headlines ("Welcome back, Damir! 👋")
- Hype words (supercharge, seamless, unlock, magic)
- Unverified claims ("Loved by 10,000+ teams")
- Placeholder data ([X], 123,456)
- Stock placeholder text
