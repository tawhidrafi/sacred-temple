# Tokens

Token values for unslop spacing, color, type.

## Spacing

- 4px grid base
- Compact panels: 16px
- Cards: 20-24px
- Page edges: 24-32px
- Navigation rows: 32-36px tall, 2-4px between
- Icon gap to label: 8 or 10px

## Color

- One neutral ramp (graphite, warm, or ink)
- Three text roles: primary, secondary, muted
- One accent with 4.5:1 contrast on text
- Semantic colors: green for good, red for error (toned down)

## Type

- Weights 400 and 500, 600 at most
- No 700-900 headings
- No gradient text
- Sentence case
- tabular-nums for numbers
- No italic for emphasis
- No negative letter spacing on small text

## Radius

- Controls: 8-10px
- Cards: 12-16px
- Panels: 14-20px
- Inner radius = outer radius - padding (never less than 4)
