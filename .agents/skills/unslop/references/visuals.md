# Visuals

Visual style reference for unslop.

## What works

- One bright element per screen
- Quiet chrome with tinted neutrals
- Text on calm space
- Real product, real material
- 4px spacing grid
- One neutral ramp, three text roles, one accent
- Line icons at 16-18px with 1.5 stroke
- Sentence case, no uppercase tracked labels
- Nested radii (inner = outer - padding)
- Subtle motion: quick color/surface change on hover, tiny scale down on press

## What fails

- Purple gradients, glows, gradient text
- Emoji labels, "New ✨" badges
- Glossy blobs, neon borders
- Uppercase tracked labels
- Pulsing elements, uneven spacing
- animate-pulse, animate-ping on non-live elements
- transition-all, hover:scale on cards
