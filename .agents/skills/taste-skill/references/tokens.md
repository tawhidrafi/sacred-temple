# Tokens

Colour, type, layout tokens for tasteskill.

## Colour ramp

Graphite, warm, ink neutral ramps. One accent.

## Type

One family for interface, plus at most one partner (mono for figures, display for headlines). Weights 400 and 500, 600 at most.

## Layout

Page edges 24-32px. Cards 20-24px. Compact panels 16px. Navigation rows 32-36px tall.

## Spacing

4px grid. Multiples of 4. 2px step for nudges inside small controls.
