## Section 2: Place deal

Variety without effects:
- The offer and the place deal different compositions
- Never two sections round one picture
- One type moment (address or name set large)
- One main action per screen
- List text 16px
- Flat grounds, square photographs
- One button style
- No effect, ground, loop, fragment, or tab
